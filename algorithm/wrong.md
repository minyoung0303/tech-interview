# 오답 노트

> **규칙: 4줄만 쓴다. 5분 넘기지 않는다.**
> 가장 중요한 건 마지막 줄(**다음에 할 것**)이다. 감상이 아니라 **행동 규칙**으로 쓴다.
>
> 재풀이 스케줄: **D+1 · D+3 · D+7**. 다 풀면 `[x]` 로 체크한다.
> 새 문제 3개보다 틀린 문제 1개 재풀이가 점수를 더 올린다.

---

```
막힌 지점:

```

## 예시 (감을 잡는 용도. 실제로는 이 위에 쌓는다)

### 2026-09-14 | Day 1
문제: 백준 2178 미로 탐색
유형: BFS (최단거리)
막힌 지점: `visited` 표시를 큐에서 **꺼낼 때** 했다 → 같은 칸이 큐에 여러 번 들어가서 시간 초과
다음에 할 것: BFS는 **큐에 넣는 순간 visited 표시**를 조건반사로. 예외 없음
재풀이: D+1 [ ]   D+3 [ ]   D+7 [ ]

### 2026-09-14 | Day 1
문제: 백준 11047 동전 0
유형: 그리디
막힌 지점: 그리디가 왜 되는지 근거를 못 댔다. 동전이 **배수 관계**라는 조건을 안 봤다
다음에 할 것: 그리디를 쓸 때는 **"반례가 없는 이유"를 한 문장으로** 말해본다. 못 하면 DP로 돌린다
재풀이: D+1 [ ]   D+3 [ ]   D+7 [ ]

## 모의 테스트 기록 (Day 7 · Day 14)

| 날짜 | 문제 수 | 푼 수 | 실패 원인 분류 | 다음 주에 보강할 것 |
|---|---|---|---|---|
|  |  |  | A 유형 미인지 / B 구현 / C 시간초과 / D 반례 |  |

**분류가 다음 계획을 결정한다.**
A가 많으면 유형 판정표를, B가 많으면 템플릿 타이핑을, C가 많으면 복잡도 역산을 늘린다.
