# 실제로 받은 질문 아카이브

> **이 파일이 이 저장소에서 가장 가치 높은 데이터다.**
>
> CS 노트 30개보다 "실제로 받은 질문 20개"가 다음 면접에 더 직접적으로 쓰인다.
> 같은 질문이 다른 회사에서도 나오고, 무엇보다 **내가 어떻게 답했고 왜 막혔는지**는
> 어디서도 구할 수 없는 정보다.
>
> 면접 끝난 날 **그날 안에** 쓴다. 하루 지나면 절반을 잊는다.

---

## 쓰는 방법

1. 기억나는 질문을 **순서 상관없이 전부** 나열한다 (정리는 나중에)
2. 각 질문에 내가 한 답을 **실제로 말한 대로** 적는다. 다듬지 않는다
3. 막혔으면 무엇이 없어서 막혔는지 쓴다
4. 관련 노트에 `asked_at: [회사명]` 을 추가한다

```bash
# 해당 노트의 confidence 를 낮춰서 복습 큐에 올린다
python tools/review.py notes/database/transaction.md -c 2
```
